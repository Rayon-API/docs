Rayon manages current material for supported public header flows.

1. Install an SDK and create an API key.
2. Send your source-page URL, profile and exact request.
3. Apply every returned header through your existing target client.

No script collection or preparation is needed for this flow. Explicit material
and form mode remain available for advanced integrations. Your client owns the
target request and session; successful generation does not prove target acceptance.

Start with the [quickstart](./guide/quickstart.md).
