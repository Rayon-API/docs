# RayonAPI documentation

Product documentation for the material-only Shape generation API, Python/JavaScript SDKs and client-owned target integration.

Canonical documentation: https://docs.rayonapi.com/

```sh
npm ci
npm test
npm run dev
```

The docs contain the public contract and illustrative integration code. Proprietary generation code and real protection material are not included. Version 1 replaces the URL-only API; see [migration](./guide/migration.md).
