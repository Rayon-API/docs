# RayonAPI documentation

Public Markdown documentation, OpenAPI schema and illustrative examples for Shape generation.

Canonical site: [docs.rayonapi.com](https://docs.rayonapi.com/). This repository's VitePress build checks content; the styled live site is maintained separately.

```sh
npm ci
npm test
npm run dev
```

Read [quickstart](./guide/quickstart.md), [material collection](./guide/preparation-walkthrough.md), [request fields](./reference/shape.md) and [usage](./reference/usage.md). All target examples use reserved domains; no proprietary protection source or live target fixtures are included.
